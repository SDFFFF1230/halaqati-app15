# حَلَقَتي — حزمة التطبيق (PWA)

## محتويات الحزمة
- `index.html` : الصفحة الرئيسية للتطبيق (مع شاشة تحميل)
- `app.js` : كود التطبيق جاهزاً (لا يحتاج أي بناء)
- `manifest.json` : بيانات التطبيق (الاسم، الألوان، الأيقونات)
- `service-worker.js` : يجعل التطبيق يعمل دون إنترنت
- `icons/` : أيقونات الشعار المعتمد بكل الأحجام (بما فيها maskable لأندرويد)
- `source/app.jsx` : المصدر المقروء للتطبيق (للتعديل لاحقاً فقط، غير مطلوب للنشر)

## خطوات النشر
1. فكّ ضغط الملف، ثم ارفع **الملفات نفسها** (وليس ملف الـ ZIP) إلى مستودع GitHub جديد، بحيث يكون `index.html` في جذر المستودع.
2. من المستودع: Settings ← Pages ← اختر الفرع `main` والمجلد `/ (root)` ← Save.
3. انتظر دقيقة ثم افتح الرابط الذي يظهر (يشبه `https://اسمك.github.io/اسم-المستودع/`).
4. جرّب الرابط من هاتف أندرويد بمتصفح Chrome: يجب أن يظهر خيار «تثبيت التطبيق / إضافة إلى الشاشة الرئيسية».
5. لتحويله إلى ملف تطبيق أندرويد: ادخل موقع PWABuilder.com والصق رابط الموقع، ثم اختر Android وحمّل الحزمة.

## ملاحظات مهمة
- أول تشغيل يحتاج إنترنت مرة واحدة لتحميل المكتبات، وبعدها يعمل دون إنترنت.
- بيانات التطبيق تُحفظ على الجهاز مرتبطة بعنوان الموقع؛ **لا تغيّر عنوان الموقع بعد توزيع التطبيق** وإلا لن تظهر البيانات القديمة. وننصح دائماً بأخذ نسخة احتياطية من الإعدادات.
- عند إصدار نسخة جديدة: غيّر رقم `VERSION` داخل `service-worker.js` ليصل التحديث للمستخدمين.
